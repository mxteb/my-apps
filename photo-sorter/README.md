# فرز الصور

تطبيق Flutter (آيفون وأندرويد) يعرض عليك كل صورك وفيديوهاتك واحدًا تلو الآخر:
اسحب **يمينًا للإبقاء** و**يسارًا للحذف**، ثم راجع القائمة وأكّد الحذف.

## المزايا
- يمر على كل الصور والفيديوهات، مع تصفية: الكل / المكررة / الصور / الفيديوهات.
- يكشف المكرر والمتشابه تلقائيًا (بصمة بصرية dHash) ويضع عليه علامة "مكررة" مع صورة الأصل.
- يحفظ تقدمك بعد كل اختيار، فتكمل من حيث توقفت.
- زر "استراحة" للمراجعة، وزر تراجع عن آخر اختيار.
- الحذف ينقل الملفات إلى سلة المحذوفات (آيفون: "المحذوفة مؤخرًا"، أندرويد 11+: سلة المهملات).

## التشغيل
1. ثبّت Flutter: https://docs.flutter.dev/get-started/install
2. وصّل جوالك بالكمبيوتر (أو شغّل محاكي).
3. داخل مجلد المشروع:
   ```
   flutter pub get
   flutter run
   ```
   - آيفون: يحتاج جهاز ماك وبرنامج Xcode.
   - أندرويد: يحتاج Android Studio.

## الملفات
- `lib/sorter.dart` الحالة، الحفظ، الحذف، وكشف المكرر
- `lib/screens/` شاشات البداية والفرز والمراجعة والانتهاء
- `lib/widgets/swipe_card.dart` بطاقة البولارويد القابلة للسحب
- `lib/theme.dart` الألوان والخطوط
