# my-apps

مجموعة البرامج التي أبنيها، كل برنامج في مجلد مستقل.

| المجلد | الوصف |
|---|---|
| [`photo-sorter/`](photo-sorter/) | تطبيق Flutter لفرز كل الصور والفيديوهات بالسحب (يمين للإبقاء، يسار للحذف)، مع كشف المكرر، وضع اللعب، وتشغيل الفيديو. يعمل بدون إنترنت. فلتر الفترة الزمنية، واختيار ألبوم أو أكثر للفرز منها. الإصدار 1.6.0 |
| [`youtube-player/`](youtube-player/) | «شوف»: مشغّل يوتيوب خفيف بلا إعلانات ولا حساب. بحث، جودة حتى 1080p، تشغيل في الخلفية، تنزيل صوت وفيديو، مفضلة وسجل. الإصدار 1.0.0 |
| [`duplicate-photos/`](duplicate-photos/) | سكربت Python أولي لكشف الصور المكررة (بصمة SHA-256 للتطابق التام وبصمة بصرية للمتشابه) |

ملف التثبيت لأندرويد: [`photo-sorter/apk/photo_sorter_v1.6.0.apk`](photo-sorter/apk/photo_sorter_v1.6.0.apk) (افتحه ثم اضغط زر التنزيل).

ملف تثبيت «شوف»: [`youtube-player/apk/shoof_v1.0.0.apk`](youtube-player/apk/shoof_v1.0.0.apk)
