# my-apps

مجموعة البرامج التي أبنيها، كل برنامج في مجلد مستقل.

| المجلد | الوصف |
|---|---|
| [`photo-sorter/`](photo-sorter/) | تطبيق Flutter لفرز كل الصور والفيديوهات بالسحب (يمين للإبقاء، يسار للحذف)، مع كشف المكرر، وضع اللعب، وتشغيل الفيديو. يعمل بدون إنترنت. الإصدار 1.4.0 |
| [`duplicate-photos/`](duplicate-photos/) | سكربت Python أولي لكشف الصور المكررة (بصمة SHA-256 للتطابق التام وبصمة بصرية للمتشابه) |

ملاحظة: ملفات APK لا تُرفع هنا (حجمها كبير)، وتُبنى من السورس.
