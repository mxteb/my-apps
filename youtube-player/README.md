# شوف (Shoof)

مشغّل خفيف لمقاطع يوتيوب على أندرويد، بلا إعلانات ولا حساب ولا خدمات Google. مبني بـ Flutter.

ملف التثبيت: [`apk/shoof_v1.0.0.apk`](apk/shoof_v1.0.0.apk)

## المميزات
- البحث مع اقتراحات، ولصق أو مشاركة أي رابط يوتيوب (مقطع، Shorts، قائمة تشغيل) إلى التطبيق.
- التشغيل بجودة حتى 1080p أو أعلى مع اختيار الجودة والسرعة، وملء الشاشة، والنقر المزدوج للتقديم والإرجاع 10 ثوانٍ.
- وضع «صوت فقط»، والتشغيل في الخلفية والشاشة مقفلة مع إشعار وأزرار تحكّم.
- مشغّل مصغّر أسفل الشاشة أثناء التصفّح.
- تنزيل الصوت (m4a) أو الفيديو بأي جودة حتى 1080p (يُدمج الصوت والصورة على الجهاز) إلى مجلّد Movies/Shoof أو Music/Shoof، وتشغيله بلا إنترنت.
- المفضلة، وسجل المشاهدة، ومتابعة المقطع من حيث توقفت. كل ذلك محفوظ على الجهاز فقط.
- صفحة القناة ومقاطعها، وقوائم التشغيل.
- المقاطع المقيّدة بالعمر: تُشغَّل عبر صفحة يوتيوب داخل التطبيق بعد تسجيل الدخول الاختياري من الإعدادات.

## البنية
- `lib/yt.dart`: جلب الروابط عبر مكتبة `youtube_explode_dart`.
- `lib/player.dart`: حالة التشغيل في الواجهة.
- `android/.../PlaybackService.kt`: مشغّل ExoPlayer (Media3) داخل خدمة، يدمج الصورة والصوت المنفصلين ويعمل في الخلفية.
- `android/.../MainActivity.kt`: الجسر بين Flutter وأندرويد، ودمج التنزيلات (MediaMuxer) وحفظها.

## البناء
```
flutter build apk --release
```
يُبنى لمعالجات arm فقط ليبقى الحجم أقل من 50 م.ب.

## ملاحظة
يعتمد التطبيق على طريقة غير رسمية لقراءة يوتيوب، فإذا غيّر يوتيوب شيئًا قد يتوقف التشغيل مؤقتًا حتى تحديث المكتبة.
